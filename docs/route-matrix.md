# Dewdora route and API contract

Generated from `php artisan route:list --path=api/v1 --json` and checked against `backend/routes/api.php`, controllers, requests, resources, frontend services and App Router files. The API base is `/api/v1`. All `/admin/*` API routes require `auth:sanctum` and the custom `AdminMiddleware` (active user with an active `Role` whose slug is `admin`). The model has `role_id`, not a permissions pivot or Spatie package. The browser sends a bearer token; the public API is anonymous.

The canonical write routes above are the only CRUD endpoints the browser calls. List endpoints return Laravel collection `data` plus `meta`; details and writes return `ApiResponse` with `success`, `message`, and `data`. Media list uses `data.media` and `data.pagination`. Public category/tag/brand detail embeds paginated nested lists. The service layer handles pagination and option loading; no frontend URL is guessed from the admin page name.

## Run checks

From `backend/`, install Composer dependencies, set a development `.env`, migrate and seed an **isolated** database, run `php artisan route:list --path=api/v1`, then `php artisan test`. Run `php artisan storage:link` to serve uploaded images.

From `frontend/`, run `npm ci`, `npm run lint`, `npm run typecheck`, and `npm run build`. To run browser acceptance, start Laravel at `http://127.0.0.1:8000` and Next at `http://127.0.0.1:3000`, seed a temporary administrator in the isolated database, install Playwright Chromium with `npx playwright install chromium`, and set `E2E_ADMIN_EMAIL` and `E2E_ADMIN_PASSWORD` before `npm test`. The script creates and removes its own records; it requires an isolated environment because it tests writes and deletes.
